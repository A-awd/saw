# Launcher standard

Claude, Codex, ChatGPT, Hermes, and future agents are interchangeable launchers. No launcher owns authoritative memory.

## Launch sequence

1. Open `A-awd/saw-production`.
2. Inspect the latest authorized GitHub branch, commit, and repository visibility.
3. Read `README.md`, `AGENTS.md`, `STATE.md`, `HANDOFF.md`, and relevant `DECISIONS.md` records.
4. Continue only from approved GitHub state and only with public-safe material while the repository is public.

After meaningful authorized work, update public-safe state, handoff, and decisions; validate; then commit and push. Platform-local context is non-authoritative. Do not merge while the visibility blocker remains.
